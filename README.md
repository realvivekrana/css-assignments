## 🚀 How to Run the Assignments

No package installation or build tools are required for these basic HTML and CSS assignments.

1. Download or clone the repository.
2. Open the folder in Visual Studio Code.
3. Choose an assignment folder, such as `CSS A_1`.
4. Open its HTML file in a browser, or use the VS Code Live Server extension.
5. Edit the CSS file to experiment with different styles.

**Important:** Keep supporting images in their original assignment folders so that the relative image paths continue to work.
